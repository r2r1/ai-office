# Чек-лист самостоятельного прогона AI-Office

Пошаговый план, чтобы лично прогнать офис от старта до результата и оценить каждую
способность по факту, а не по докстрингу. Опирается на находки
[capability-audit-2026-07-16.md](capability-audit-2026-07-16.md) и
[pre-release-audit-2026-07-15.md](pre-release-audit-2026-07-15.md) — там же смотреть
"что уже проверено", если пункт хочется пропустить.

Формат каждого пункта: **Что делать → Что смотреть → Критерий "работает"**. Ставь ✅/⚠️/❌
и заметку в столбец "Результат" по ходу прогона.

## Как читать результат

- Если пункт **✅** — способность подтверждена лично, не с чужих слов.
- Если **⚠️** — работает, но с оговоркой (симуляция вместо реального внешнего вызова, деградация
  вместо полной функции) — реши, приемлемо ли это для твоего запуска.
- Если **❌** — способность не работает в ТВОЁМ окружении прямо сейчас; проверь, это баг кода
  или недостающая инфраструктура (Docker, токен, `ALLOW_CODE_EXECUTION`) — большинство ❌ из
  прошлого аудита оказались вторым случаем, не багом.
