# UX / Product аудит — 2026-07-06 (свежий, вживую на demo-preview)

Предыдущие аудиты (`audit-ux-2026-07.md`, `audit-dd-2026-07*.md`) считаются
устаревшими: часть их находок уже исправлена в коде за последние коммиты.
Этот документ проверен **вживую** на `demo-preview` (порт 5599, DEMO_MODE=1,
без расхода токенов) — не по чтению исходников.

Три роли, один документ: /ux-researcher (что видит и чувствует пользователь),
/ux-architect (структура/токены/адаптив), /product-manager (что с этим делать
и в каком порядке).

## 0. TL;DR

Старые находки про топбар-перегрузку и «дефолт не на офисе» **закрыты**:
топбар сжался до 5 зон, дефолт-вью — «Сводка» (разумный компромисс, не
`team` и не голый `office`). Навигация — 7 вкладок вместо 8, чище.

Но появились **новые, не задокументированные** проблемы, которые старые
аудиты не могли поймать (их не было на момент написания):
1. **Мобильная адаптация сломана буквально** — нижняя навигация обрезана
   по правому краю (вкладка «Аккаунт» не помещается), под ней ~150px
   мёртвого чёрного пространства на 375×812.
2. **Горизонтальный скролл вложенных табов без видимого аффорданса** —
   вкладка «Компания» имеет 7+ подвкладок (Профиль/Цели/Роли/Скиллы/
   Интеллект/Лимиты/Хранилище/…), последняя обрезана словом «Ин…», скролл
   есть, но пользователь не видит, что там что-то скрыто.
3. **Поля ввода целей обрезают подсказки** — placeholder «Цель — например:
   заявки с сайта кажд[ую неделю]» и «Как измеряем (ли[дов]…» обрезаются
   на десктопе уже при обычной ширине карточки.
4. **World Model / Objectives доехали до UI, но без имени и без Gap-числа.**
   `Компания → Цели` показывает «Где компания сейчас» (это и есть
   `world.snapshot()` из BOS) и пустое состояние целей — но нет явного
   индикатора «разрыв к цели X%», хотя бэкенд (`office/objectives.py`,
   `office/world.py`) это уже считает по последним 4 коммитам roadmap-аудита.
5. **Инлайн-стили всё ещё доминируют**: `ProjectView.tsx` — 147 `style={{`,
   `CompanyView.tsx` — 110, при наличии токен-файла `styles/design.css`.
   Дизайн-система существует как файл, но не как дисциплина использования.

## 1. UX Research — что видит пользователь сейчас (живой прогон)

**Сводка (дефолт-вью).** Здоровье компании 🔴 38/100, по отделам (Технический
🔴26, Маркетинг 🟡50), автономность «Под руководством» с явным переключателем
уровня (scout/guided/trusted/autonomous — хорошо, это первоклассный UX для
доверия), ключевые метрики (задачи 1/9, прогресс 43%, лиды 3, расход $0.02).
Плотно, но читаемо — один экран отвечает «всё ли хорошо» за ~3 секунды,
это то, чего старый аудит требовал и не находил.

**Офис (изометрическая сцена + чат).** Сцена показывает комнаты (Research
Lab, Strategy, Sales, Dev Studio, Meeting Room) с аватарами занятых ролей и
живой чат/журнал справа, который реально показывает рассуждения агента
(«Проверю, какие изображения доступны для галереи…»). Это тот самый
«wow», который в старом аудите был спрятан за онбордингом — сейчас он
доступен сразу с одного клика по навигации, но всё ещё не дефолт.

**Работа (план/проекты/процессы/инициативы).** Хорошая консолидация: было
разрозненно, теперь один раздел с 4 подвкладками. «Инициативы» — честный
пустой стейт («AI предложит их сам… или предложи свою идею») с CTA — хорошая
находка, соответствует принципу автономности из CLAUDE.md. «Проекты»
показывает карточку с прогрессом 1/9, командой по ролям, этапами с
чекмарками — читаемо и по существу.

**Компания → Цели.** Прямое попадание в BOS-словарь: «Где компания сейчас»
(World Model срез) + «Цели компании — к чему движемся» (Objectives). Пустое
состояние честно объясняет, что цель без метрики не участвует в оценке
(соответствует инварианту `measured_by` из последнего коммита). Это сильная
находка — редкий случай, когда внутренняя архитектура БЕЗ перевода легла
в понятный пользователю текст.

**Эмоциональная дуга.** Уверенность (Сводка) → любопытство (Офис, живой чат)
→ лёгкая усталость от вложенности (Компания, 7 подвкладок с горизонтальным
скроллом) → на мобильном — раздражение (обрезанная навигация).

## 2. UX Architecture — структура, токены, адаптив

**Design tokens:** `webapp/src/styles/design.css` существует (CSS custom
properties), но 400+ инлайн `style={{}}` в `ProjectView`/`CompanyView`
означают, что токены не enforced — новый компонент с вероятностью выше 50%
допишет ещё один hex внутри `style={{color: "#..."}}`. **Рекомендация:**
не переписывать существующее (это месяцы работы без функциональной отдачи),
но **закрыть кран** — на новые PR требовать переменные из `design.css`,
плюс точечно исправить самые растянутые компоненты (Objectives-карточки,
у которых сейчас обрезается текст — заодно и баг, и токенизация).

**Layout/responsive:** нижняя мобильная навигация (`NavRail` в мобильном
режиме, судя по `webapp/src/app/App.tsx` isMobile-ветке) не имеет
`overflow-x: auto` или сжатия элементов — 7 вкладок с иконками+подписями не
помещаются в 375px и обрезаются по краю без скролла и без переноса в «ещё».
Приоритетный баг, не стилистика — **функционально теряется вкладка
«Аккаунт»** на мобильном.

**Вложенные табы (Компания, Работа):** горизонтальный скролл есть, но без
градиентной тени/стрелки-подсказки на обрезанном крае — пользователь должен
случайно свайпнуть, чтобы узнать, что там ещё 3 вкладки. Дёшево чинится
CSS-маской (`mask-image: linear-gradient(...)`) без правки логики.

**Компонентная иерархия:** `Card`/кнопки переиспользуются (видно в
скриншотах — единый радиус, единая рамка), но текстовые инпуты с
плейсхолдерами-подсказками («Цель — например: …») не имеют минимальной
ширины/переноса строк — контент архитектурно не продуман для длинных
русских фраз (короче английских эквивалентов, зато чаще перенос ломается
на служебных словах).

**Тема (light/dark):** переключение работает корректно на всех проверенных
экранах (CSS-переменные), включая новую версию «Компания → Цели» — это
пример того, что theming-фундамент сделан правильно и не нужно трогать.

## 3. Product — приоритеты и план

Зрелость UX сейчас (переоценка): **7/10** (было 6/10) — топбар и навигация
подтянуты, но родились свежие адаптивные баги, которых не было в прошлой
версии интерфейса (значит, регрессия либо не тестировалась на мобильных
вьюпортах при последних правках).

### Сейчас (эта неделя, дёшево)
1. **Починить мобильную нижнюю навигацию** — либо сжать в иконки без подписей
   на <400px, либо превратить последний пункт в «Ещё» с шитом. Это
   единственная находка уровня «пользователь не может открыть вкладку».
2. **Обрезающиеся placeholder'ы в полях целей** (`CompanyView.tsx`, вкладка
   «Цели») — расширить инпут/перенести текст, тривиальная CSS-правка.
3. **Визуальный намёк на скролл вложенных табов** (Компания/Работа) —
   градиентная маска с двух краёв.

### Месяц
4. **Явное число «разрыв к цели»** на Сводке и в `Компания → Цели` —
   бэкенд (`world.py`, `objectives.py`) это уже считает, интерфейс сейчас
   показывает сырые метрики, но не единый % расхождения плана и факта —
   это ровно тот Gap Analysis, ради которого писались последние 4 коммита
   roadmap-аудита, и сейчас это инвестиция без видимой отдачи пользователю.
5. **Токенизация по факту, не по декларации** — точечно вынести цвета из
   3-5 самых «горячих» компонентов (Objectives card, Project card) в
   переменные `design.css`, не трогая остальное.

### Квартал
6. Довести историю до конца: если Работа/Компания продолжат обрастать
   подвкладками, нужен единый паттерн вложенной навигации (табы → возможно
   боковое дерево), а не расширение линии табов до бесконечности.

### Не трогать сейчас
- Архитектурная база (BOS) — по решению CTO от 2026-07-03 заморожена до
  конкретного триггера; выше не архитектурные, а UI/полировочные правки,
  они этому решению не противоречат.
- Theming/dark-light — уже корректно, не находка.
