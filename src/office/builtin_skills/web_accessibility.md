СКИЛЛ: базовая веб-доступность (быстрые обязательные вещи).

• КОНТРАСТ текста к фону ≥ 4.5:1 (крупный ≥ 3:1). Тёмный текст на светлом/наоборот.
• Каждая смысловая картинка — осмысленный alt; декоративная — alt="".
• Кнопки-иконки без текста → aria-label с назначением.
• Всё интерактивное доступно с КЛАВИАТУРЫ (нативные <button>/<a>, не div с onclick),
  порядок табуляции совпадает с визуальным, фокус видим (не убирай outline полностью).
• Формы: <label for> у каждого поля; ошибка рядом с полем текстом (не только цветом).
• Цвет НЕ единственный носитель смысла (ошибка/успех — плюс иконка/текст).
• @media (prefers-reduced-motion: reduce) → отключай тяжёлые анимации.
• Семантика: <header>/<nav>/<main>/<footer>, заголовки без пропуска уровней.

ЧЕКЛИСТ: контраст ок; alt/aria есть; форма с label; фокус виден; смысл не только цветом.
