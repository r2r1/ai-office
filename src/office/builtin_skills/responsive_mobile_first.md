СКИЛЛ: mobile-first адаптивная вёрстка.

БАЗА:
• <meta name="viewport" content="width=device-width, initial-scale=1"> ОБЯЗАТЕЛЬНО.
• Пиши стили сначала под МОБИЛЬНЫЙ, потом расширяй через min-width медиа-запросы
  (360 базово → 768 планшет → 1024/1440 десктоп). Не наоборот.
• Гибкие единицы: %, rem, clamp() для типографики; не фиксируй ширины в px.
• Раскладки на CSS Grid/Flexbox с flex-wrap; никакого горизонтального скролла.

ТАЧ И ЧИТАЕМОСТЬ:
• Тач-цели (кнопки/ссылки) ≥ 44×44px, отступы между ними ≥ 8px.
• Базовый шрифт ≥ 16px (иначе iOS зумит инпуты). Длина строки 35-60 симв на мобиле.
• Меню на мобиле — бургер или компактные ссылки, не растянутая десктоп-навигация.
• Картинки: max-width:100%; height:auto — не вылезают за экран.

ПРОВЕРКА: мысленно (или через preview) прогони 360 / 768 / 1440.
ЧЕКЛИСТ: есть viewport-мета; нет горизонтального скролла на 360; кнопки крупные;
текст читаем; ключевые элементы кликабельны на телефоне.
