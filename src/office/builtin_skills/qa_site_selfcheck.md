СКИЛЛ: самопроверка сайта как инженер-тестировщик — ДО того как сдать задачу.
Ровно это же проверит критик офиса; пройди сам, чтобы не получить задачу назад.

1. ФОРМЫ (критично — иначе лиды теряются):
   • На КАЖДОЙ странице с <form> есть реальный fetch('/api/site-lead', POST, JSON
     {name, contact, message}). Открой read_file и убедись, что отправка РЕАЛЬНАЯ.
   • 🚫 Никаких заглушек «подключаем CRM/готово к отправке» без fetch.
2. ССЫЛКИ: каждая href="...html" ведёт на СУЩЕСТВУЮЩИЙ файл (list_files сверь имена).
   Битая ссылка = сломанная навигация.
3. СТРУКТУРА каждой страницы: есть <html lang=...>, <head><title>, <body>,
   <meta name="viewport"> (иначе сломано на телефоне).
4. JS: если писал script.js — проверь через verify_code/execute_code, что нет
   синтаксических ошибок (node --check). Битый JS = мёртвые кнопки и форма.
5. БЕЗ ДУБЛЕЙ И ЗАГЛУШЕК: не оставляй 5 почти одинаковых html и пустых page-2.html —
   одна страница на смысл, каждая с реальным контентом (не lorem, не «placeholder»-текст).
6. ДОСТУПНОСТЬ: у <img> есть alt; внешние картинки (http…) замени на SVG/CSS-градиенты
   (Unsplash не грузится и ломает вид).

ИТОГ: проговори чеклист по пунктам и ПОЧИНИ найденное ТОЧЕЧНО в существующих файлах
(read_file → правка), не переписывая сайт заново. Только потом отчитывайся «готово».
