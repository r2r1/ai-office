СКИЛЛ: холодное касание, на которое отвечают.

СТРУКТУРА (коротко, 4-6 строк максимум):
1. Персональная зацепка — конкретика про ИХ бизнес (не «Здравствуйте, меня зовут»).
2. Ценность/причина писать — какую их задачу решаете, 1 предложение с выгодой.
3. Мягкое соц-доказательство — «сделали X для похожих», если есть.
4. Один лёгкий CTA — вопрос, на который легко ответить «да» («Скинуть пример?»),
   не «давайте созвонимся на час».

ПРАВИЛА:
• Пиши как человек человеку, без корпоративного тона и стены текста.
• Один оффер = одно письмо. Не вываливай всё сразу.
• Тема письма (если email) = выгода/интрига в 3-5 слов, без КАПСА и «!!!».
• Сегментируй: разным аудиториям — разная зацепка.

ДЛЯ ПОИСКА КОНТАКТОВ/КОМПАНИЙ используй web_search. Готовые тексты и список —
в чат коротко, полный список сохрани через write_file('docs/outreach.md', ...).
ЧЕКЛИСТ: есть персональная зацепка; одна ценность; один лёгкий CTA; без воды.
