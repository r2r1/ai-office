СКИЛЛ: on-page SEO без внешних зависимостей.

НА КАЖДОЙ СТРАНИЦЕ:
• <title> уникальный, до ~60 симв: «<Услуга> в <городе> — <выгода/цена от>».
• <meta name="description"> до ~155 симв, с выгодой и призывом (влияет на CTR).
• Ровно ОДИН <h1> = главный запрос страницы. Далее h2/h3 логичной иерархией.
• ЧПУ-URL латиницей по смыслу: /natyazhnye-potolki-kislovodsk, не /page2.
• Внутренняя перелинковка: с главной на посадочные и обратно (меню + блоки).
• Alt у смысловых картинок; SVG для декоративной графики.

ПОД ЛОКАЛЬНЫЙ/КОММЕРЧЕСКИЙ СПРОС (сетка страниц, а не один лендинг):
• Отдельные страницы под кластеры: «цена», «в новостройке», по городам/районам,
  по типам (матовый/глянцевый/с подсветкой). У каждой — свой title/h1/контент.
• Блок FAQ (вопрос-ответ по реальным сомнениям) — и текстом, и по возможности
  JSON-LD FAQPage в <script type="application/ld+json"> (без внешних библиотек).

🚫 Не переспамливай ключами — пиши для человека, ключ в title/h1/первом абзаце.
ЧЕКЛИСТ: у каждой страницы уникальные title/description/h1; ЧПУ-URL; страницы
связаны навигацией; есть FAQ на главной/ключевых.
