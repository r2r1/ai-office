СКИЛЛ: подключить счётчик веб-аналитики (Яндекс.Метрика / GA4 / VK Pixel) на сайт.

ГЛАВНОЕ ПРАВИЛО: код счётчика — это <script>-СНИППЕТ в <head> КАЖДОЙ существующей
страницы сайта (read_file → вставить перед </head> → write_file тот же файл).
🚫 НИКОГДА не создавай отдельную страницу под счётчик (metrika.html, analytics.html
и т.п.) — это бессмысленная заглушка, она не считает посетителей и валит приёмку
(реальный прод-кейс: битый metrika.html чинили 6 попытками).

ПОРЯДОК:
1. Номер счётчика/ID — из брифа или ответа клиента. Нет ID → ask_user с инструкцией,
   где его взять (Метрика: metrika.yandex.ru → «Добавить счётчик» → скопировать номер).
   Не выдумывай ID-плейсхолдер «12345678» в проде.
2. list_files → read_file каждой html-страницы → вставь сниппет перед </head>.
3. Сниппет Метрики — официальный (ym(ID, "init", {...}) + <noscript>); GA4 — gtag.js
   с ID G-…; VK Pixel — официальный код из рекламного кабинета.
4. Проверь: сниппет есть НА ВСЕХ страницах, ни одна новая страница не создана.

В конце ответа ОДНОЙ строкой: «Изменения: счётчик <какой> добавлен в <какие файлы>».
