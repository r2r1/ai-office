СКИЛЛ: премиальный лендинг на Vue 3 БЕЗ шага сборки (esm.sh) — статика в site/.

КОГДА УМЕСТЕН: нише полезна ЖИВАЯ интерактивность данных — калькулятор стоимости,
конфигуратор услуги, фильтруемый каталог работ, многошаговая форма. Если ничего из
этого не нужно — честнее взять статический скилл, Vue «для галочки» не бери.

⚠️ ЕСЛИ site/index.html УЖЕ СУЩЕСТВУЕТ на другом стеке — это ПРАВКА: сохрани стек и
контент, НЕ переписывай сайт на Vue ради смены стека. Vue — для НОВОГО сайта.

СТРУКТУРА (всё в site/):
• site/index.html — единственная точка входа:
  - <script type="importmap"> с vue c esm.sh;
  - <div id="app"></div> с шаблоном или createApp с template;
  - <script type="module" src="app.js"> — приложение.
• site/styles.css — стили (дизайн-токены в :root), site/app.js — логика.

ОБЯЗАТЕЛЬНЫЙ importmap (вставь как есть, версия фиксирована):
  <script type="importmap">
  {"imports": {"vue": "https://esm.sh/vue@3.4.38/dist/vue.esm-browser.prod.js"}}
  </script>

ПРИЁМ: createApp({ data/computed/methods }) + шаблон прямо в index.html внутри
#app — это даёт реактивность без JSX/SFC/сборки. reactive-состояние для
калькулятора/фильтра; v-model на полях формы; transition для появления секций.

ДИЗАЙН: та же планка, что в скилле «Премиальный сайт (без 3D)» — дизайн-токены,
палитра ИЗ строки «Стиль: …» в docs/site_content.md (каталог направлений — в скилле
«Продающий лендинг»), типо-шкала, hover/focus, адаптив, никакого лорем-ипсума.
🚫 Никаких Tilda/Webflow/Wix. SVG-иконки, не эмодзи.

ФОРМА ЗАЯВКИ (КРИТИЧНО): submit-хэндлер РЕАЛЬНО шлёт
fetch('/api/site-lead', {method:'POST', headers:{'Content-Type':'application/json'},
body: JSON.stringify({name, contact, message})}) с валидацией (на blur), статусом
кнопки («Отправляем…» → «Заявка отправлена») и экраном «спасибо».
🚫 Заглушки («подключаем CRM», console.log вместо fetch) ЗАПРЕЩЕНЫ. Бэкенд не строй.

ПРОВЕРКИ ПЕРЕД СДАЧЕЙ:
1. importmap указывает на esm.sh/vue, app.js — type="module", монтируется без ошибок.
2. Есть ХОТЯ БЫ ОДНА реактивная секция, ради которой Vue взят (калькулятор/фильтр/шаги).
3. Форма реально шлёт POST /api/site-lead и показывает подтверждение.
4. Дизайн-токены, адаптив, палитра из «Стиль: …».

ВЫПОЛНЕНИЕ: пиши файлы через write_file. Публиковать не нужно — офис опубликует site/ сам.
В конце ответа ОДНОЙ строкой: «Изменения: …» (или что создано).
