СКИЛЛ: превратить данные в решение.

1. ВОЗЬМИ доступные цифры: заявки (раздел «Лиды»), посетители, конверсия,
   источники, средний чек — из брифа/файлов/интеграций.
2. ПОСЧИТАЙ ключевое: конверсия (лиды/посетители), CPL, воронка по этапам,
   где самый большой ОТВАЛ.
3. НАЙДИ 1-2 главных вывода: «узкое место здесь», «этот канал даёт дёшево».
4. ПРЕДЛОЖИ конкретный следующий шаг под каждый вывод (A/B оффера, докрутить
   первый экран, перекинуть бюджет на канал).

СЧИТАЙ КОДОМ, НЕ НА ГЛАЗ: если в workspace есть структурированные данные (CSV/JSON
с рядами заявок/визитов) — не оценивай цифры по памяти/навскидку. Пиши Python-скрипт
на pandas (write_file → analysis.py: `import pandas as pd; df = pd.read_csv(...)`
или `pd.read_json(...)`, `.groupby()`/`.value_counts()`/`.mean()` для конверсии,
CPL, воронки по этапам) и запусти его через execute_code — вывод в docs/analysis.md
идёт РЕАЛЬНЫМ результатом расчёта, не придуманным числом. Это системный инструмент
платформы для анализа данных (как aiogram — системный инструмент для ботов, React+
Vite+Framer Motion — для сайтов): один предсказуемый способ считать, не гадание.
Если execute_code отключён оператором (ALLOW_CODE_EXECUTION=0) или структурированных
данных нет — считай вручную по доступным цифрам и явно пометь это в отчёте.

ПРАВИЛА:
• Вывод > данные. Не «вот таблица», а «вот что это значит и что делать».
• Всегда с числами и периодом. «+14% конверсии» вместо «стало лучше».
• Мало данных — так и скажи, предложи, что начать замерять (события/цели).

СОХРАНИ: write_file('docs/analysis.md', ...) — цифры, выводы, рекомендации.
ЧЕКЛИСТ: посчитана конверсия/воронка (кодом на pandas, если есть структурированные
данные и execute_code доступен); 1-2 вывода; конкретный следующий шаг; с числами.
