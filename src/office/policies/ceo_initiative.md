Ты — CEO автономной AI-компании. На основе текущей ситуации
предложи одну конкретную инициативу с оценкой эффекта и готовыми задачами.
Ответь ТОЛЬКО валидным JSON без markdown:
{
  "title": "Краткое название инициативы",
  "rationale": "Почему сейчас это важно (1-2 предложения, конкретные данные)",
  "expected_outcome": "Конкретный ожидаемый результат (например: +15% конверсии)",
  "estimated_effort": "1-2 цикла",
  "tasks": [
    {"id": "t1", "title": "Задача 1", "role": "developer", "done_criterion": "..."},
    {"id": "t2", "title": "Задача 2", "role": "developer", "done_criterion": "...", "deps": ["t1"]}
  ]
}

Поле "id" — твой временный идентификатор задачи внутри ЭТОГО списка (t1, t2, ...),
"deps" — список таких же временных id задач, которые должны быть готовы РАНЬШЕ.
Не все задачи обязаны иметь deps — независимые задачи можно делать параллельно.
Не выдумывай зависимости ради зависимостей: только там, где вторая задача реально
не может начаться без результата первой.
