# AI-Office 🏢

Автономный офис AI-агентов в стиле пиксельной игры. Агенты сами развивают бизнес: исследуют рынок, строят стратегию, нанимают новых сотрудников и работают над задачами. Ты можешь кликнуть на любого сотрудника и поговорить с ним вживую.

## Возможности

- 🎮 **Пиксельная веб-игра** — офис с персонажами, которые ходят к столам и общаются
- 🤖 **Автономная работа** — ресёрчер → стратег → HR нанимает специалистов
- 💬 **Интерактив** — кликни на агента и задай ему любой вопрос
- 🔍 **Веб-поиск** — через DuckDuckGo (бесплатно, без ключа)
- 🔌 **Любой LLM** — OpenAI-совместимый провайдер (apinet.cloud и др.)
- 🎬 **Демо-режим** — посмотреть офис без расхода токенов

## Сотрудники офиса

| Роль | Что делает |
|------|-----------|
| 🔍 Researcher | Исследует рынок, тренды, кейсы (quick/deep режимы) |
| 📋 Strategist | Строит бизнес-план: юнит-экономика, дорожная карта |
| 👔 HR | Решает кого нанять следующим |
| 💰 Salesman | Ищет клиентов, пишет офферы |
| 💻 Developer | Строит автоматизации и AI-продукты |
| 📢 Marketer | Контент-план и продвижение |
| 📊 Analyst | Данные, метрики, аналитика |

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:
```
LLM_BASE_URL=https://apinet.cloud/v1
LLM_API_KEY=sk-your-key
LLM_MODEL=qwen3-vl-plus    # любая модель провайдера
DEMO_MODE=0                # 1 = демо без API
```

## Запуск веб-игры

```bash
python -m uvicorn server:app --reload
# открой http://localhost:8000
```

**Демо-режим** (без API):
```bash
# Windows PowerShell:
$env:DEMO_MODE=1 ; python -m uvicorn server:app --reload
```

## CLI (без игры)

```bash
python main.py                    # ресёрчер → стратег
python main.py research "вопрос"  # только ресёрчер
```

## Структура

```
ai-office/
├── server.py              # FastAPI: SSE-стрим + чат + статика
├── src/
│   ├── core/
│   │   ├── llm.py         # Единый LLM-клиент (OpenAI-формат)
│   │   └── search.py      # Веб-поиск через DuckDuckGo
│   ├── agents/
│   │   ├── researcher.py  # Ресёрчер (quick/deep)
│   │   ├── strategist.py  # Стратег
│   │   ├── hr.py          # HR (найм)
│   │   └── agent_factory.py  # Фабрика нанятых агентов
│   └── office/
│       ├── loop.py        # Автономный цикл офиса
│       ├── chat.py        # Диалог пользователя с агентами
│       ├── bus.py         # Event bus (SSE)
│       ├── registry.py    # Реестр агентов
│       └── demo.py        # Демо-сценарий
├── static/                # Пиксельная игра (canvas + JS)
└── reports/               # Отчёты и стратегия
```
