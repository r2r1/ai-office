# AI-Office

Автономный офис AI-агентов для заработка 1 млн рублей.

## Агенты

### 1. Researcher — Агент-ресёрчер
Исследует интернет, соцсети, рынки и новости. Анализирует бизнес-модели и выдаёт рекомендации на основе реальных данных.

**Запуск:**
```bash
python main.py
```

Или с кастомным вопросом:
```bash
python main.py "Какие AI-инструменты лучше всего продаются на российском рынке в 2026 году?"
```

Отчёт сохраняется в папку `reports/`.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Добавь ANTHROPIC_API_KEY в .env
```

## Структура

