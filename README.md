# AI-Office

Автономный офис AI-агентов для заработка 1 млн рублей.

## Агенты

### 1. Researcher — Агент-ресёрчер
Исследует интернет, соцсети, рынки и новости. Анализирует бизнес-модели и выдаёт рекомендации на основе реальных данных.

### 2. Strategist — Агент-стратег
Берёт отчёт ресёрчера и превращает выбранную бизнес-модель в конкретный исполнимый план: юнит-экономика, декомпозиция на задачи, дорожная карта на 90 дней, метрики и риски.

**Запуск:**
```bash
python main.py                    # полная цепочка: ресёрчер → стратег
python main.py research           # только ресёрчер
python main.py research "вопрос"  # ресёрчер с кастомным вопросом
python main.py plan reports/research_XXX.md   # стратег по готовому отчёту
```

Отчёты и планы сохраняются в папку `reports/`.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Добавь ANTHROPIC_API_KEY в .env
```
